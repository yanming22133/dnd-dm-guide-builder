# 数据包字段说明（data-schema）

数据包就是一个普通 Python 模块（`.py`），用**模块级变量**描述整本手册。
`build_guide.py` 读取它并渲染 HTML。**只有 `TITLE` 和 `CHAPTERS` 是必需的**，其余缺省会被跳过。

```python
TITLE   = "凡达林的失落矿坑 · DM 速查"   # 页面主标题
SUBTITLE= "克拉摩堡 · 雷树废墟 · 潮音洞穴"
SCOPE   = "对应模组 PDF 第 28–46 页"
VERSION = "v2026-10-14 · 首版"           # 显示在标题旁的版本徽章
```

## 1. 章节与区域（核心）

```python
CHAPTERS = [
  {
    "id":   "castle",          # 必需：锚点前缀，区域 id 会变成 castle-1, castle-2 …

    "en":   "Cragmaw Castle",
    "page": "模组 PDF 第 33–38 页",
    "nav":  "🏰 克拉摩堡",      # 可选：左侧导航显示的文字
    "maps": ["castle"],        # 可选：本章要挂哪张地图（对应 MAPS 的 key）

    # 概览区（可选，但强烈建议）
    "intro":     ["背景段 1", "背景段 2"],
    "situation": ["局势要点 1", "局势要点 2"],
    "features":  [("天花板", "15 尺"), ("门", "DC 15 力量可破")],  # (名, 说明)
    "ambience":  ["招牌氛围的描述…"],       # 可选，渲染成蓝色块
    "wander": {                              # 可选，游荡怪物表
        "title": "游荡怪物", "trigger": "骰 d20，17–20 触发",
        "table": [("1–3", "蚊蝠 (2d4)"), ("4–5", "食尸鬼 (1d4)")],
        "tip": "别用太多，以免拖沓。"
    },

    "areas":  [ ...见下... ],
    "extras": [ {"title": "结束之后", "body": ["段落…"], "xp": "200 XP",
                 "objects": ["可交互物件…"]} ],
  },
]
```

### 区域（area）的全部字段

```python
{
  "no":   "8",                       # 必需：区域编号（显示为「区域 8」）
  "name": "黑暗大厅",
  "en":   "Dark Hall",

  "read":   "念给玩家的原文（书上的 boxed text）",
  "read2":  "同一区域的第二段念白（可选）",

  "script": [ "🎬 运行脚本要点 1", "要点 2" ],   # 见 content-principles，最重要
  "info":   [ "DM 信息" ],
  "info2":  [ "补充信息" ],
  "trap":   [ "陷阱 / 机关：DC 多少、失败什么后果" ],
  "tactics":[ "战术 / 处理：敌人怎么动" ],
  "objects":[ "可交互物件 / 可调查（含对应检定）" ],
  "hook":   [ "后续伏笔插入点（可选）" ],
  "foreshadow":[ "剧情伏笔" ],
  "treasure":[ "宝藏与价值" ],
  "dev":    [ "发展：战斗/谈判后会发生什么" ],
  "senses": [ "可以这样描述：一句感官描写" ],

  "say": [ ["说话者", "台词"], ["另一个说话者", "台词"] ],

  "monsters": [ ["goblin", "2 只"], "bugbear" ],   # [key, 备注] 或直接 "key"
  "xp": "450 XP",
}
```

> **`script` 是这本手册的灵魂。** 它回答的是"这一场到底怎么带"，
> 不是"这里有什么"。写法见 `reference/content-principles.md`。

## 渲染出来的页面结构

```
顶栏（标题/版本/搜索/骰子/打印）
├─ 侧边导航（章节 → 每个区域）
└─ 正文
   ├─ 开跑前速查
   ├─ 线索链
   ├─ 承上启下（埋线 & 小支线）
   ├─ 大地图
   ├─ 各章节（概览 → 地图条 → 区域卡 → 附加）
   ├─ 衔接下一章
   ├─ NPC 谈判手册
   ├─ 怪物图鉴
   ├─ 魔法物品 / 经验表 / 陷阱 / 伏笔 / 台词 / 描述词 / 主持提示
   └─ 先攻·HP 追踪器
```

**区域卡内部顺序**（从上到下，就是 DM 现场的眼睛顺序）：

```
📖 念给玩家  →  🎬 运行脚本  →  🎯 DM 信息  →  📌 补充  →  ⚠️ 陷阱
→  🧠 战术  →  🗿 可交互物件  →  🧩 伏笔插入点  →  💡 伏笔  →  💎 宝藏
→  🔀 发展  →  👁️ 描述词  →  🗣️ 台词  →  🐺 怪物（点击跳图鉴）
```
